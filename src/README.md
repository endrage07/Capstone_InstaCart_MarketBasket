# Source Code

This directory contains the reproducible pipeline corresponding to the
Instacart Market Basket ML capstone.

The logic here mirrors the workflow implemented in the Colab notebooks:
- Data loading via KaggleHub
- Feature engineering on prior orders
- Construction of the training table
- Model training and evaluation

Notebooks are used for EDA, visualization, and interpretation.
The `src/` modules capture the reusable pipeline logic.
